API Luminary Docs

A clean, fast REST API for managing users, projects and automations. Every endpoint below is documented with live-switchable code examples.

🔑 Authentication

Authenticate requests with a bearer token in the Authorization header.

curl https://api.luminary.dev/v1/users \
  -H "Authorization: Bearer YOUR_API_KEY"
const res = await fetch('https://api.luminary.dev/v1/users', {
  headers: { Authorization: `Bearer ${API_KEY}` }
});
import requests
r = requests.get("https://api.luminary.dev/v1/users",
  headers={"Authorization": f"Bearer {API_KEY}"})

📦 Endpoints

Expand an endpoint for parameters and response details.

GET/v1/users⌄
Returns a paginated list of users in your workspace.
PARAMTYPEDESCRIPTION
limitintegerMax results per page (default 20)
cursorstringPagination cursor from a previous response
POST/v1/projects⌄
Creates a new project inside the authenticated workspace.
PARAMTYPEDESCRIPTION
namestringProject display name (required)
visibilitystring"public" or "private" (default private)
GET/v1/projects/:id⌄
Fetches full details for a single project, including members and status.
PARAMTYPEDESCRIPTION
idstringProject ID (path parameter, required)
DEL/v1/webhooks/:id⌄
Deletes a registered webhook endpoint permanently.
PARAMTYPEDESCRIPTION
idstringWebhook ID (path parameter, required)
GET/v1/webhooks⌄
Lists every webhook currently registered on the workspace.
